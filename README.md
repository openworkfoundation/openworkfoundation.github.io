# Open Work Foundation

Open infrastructure for work in the AI era.

This repository is the public site and manifesto of the Open Work Foundation.
The rendered site lives at https://openworkfoundation.github.io

## Contents

- `docs/` — site source (VitePress, EN + ES)
- `CONTRIBUTING.md` — how to add languages, initiatives, articles and papers
- `LICENSE` — MIT

## Why we exist

AI will displace millions of knowledge workers faster than labor markets can
reabsorb them. The response cannot wait for the crisis to arrive. We build and
steward open, auditable infrastructure — schemas, matching engines, public data —
so the transition is orderly, not an abyss.
